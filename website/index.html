05 / Play

Join in 30 seconds

No launchers, no modpacks, no downloads. If you have Minecraft, you're ready.

  1. 01

    Copy the IP

    Our server address is moddedrealms.minehut.gg

  2. 02

    Add the server

    Open Minecraft: Java Edition, then go to

    Multiplayer › Add Server

    Paste the IP and hit Done.

  3. 03

    Jump in

    Select Moddedrealms and click Join Server. Everything runs server-side, so there's nothing else to install.
